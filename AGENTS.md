# AGENTS.md

## Sobre o projeto

**clone-tabnews-ia**: implementação do [tabnews.com.br](https://www.tabnews.com.br) para o [curso.dev](https://curso.dev), construída com agentes de IA.

## Stack

- Next.js com App Router (diretório `app/`)
- JavaScript puro (sem TypeScript)
- Versões exatas das dependências: ver `package.json`

## Comandos

```bash
npm install
npm run dev     # servidor de desenvolvimento (porta 3000)
npm run build
npm run start
npm run lint          # ESLint (eslint-config-next + eslint-config-prettier)
npm run format        # formata os arquivos com o Prettier
npm run format:check  # verifica a formatação sem alterar arquivos
```

## Convenções

- Idioma: interface, comentários e mensagens de commit em português (pt-BR)
